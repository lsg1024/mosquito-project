# 모기 알리미 - Flutter

# 프로젝트 개요
해당 주제를 선정한 이유는 여름마다 나타나는 모기들이 오늘은 얼마나 나타나는지 알려주는 서비스를 개발해 보는 것은 어떨까 생각하다 떠오른 아이디어 입니다.
해당 서비스는 사용자가 설정한 시간에 맞춰 디바이스에 알림을 보내줘 까먹지 않고 오늘의 모기량을 알 수 있게 도움을 주는 서비스입니다.

# 대표 기능
- 스케줄링으로 오늘의 모기 값을 FireBase에 저장
- 사용자 알림 설정 기능
- 모기 알림 FCM 서비스

사용 공공 데이터 ( 서울시 모기예보제 ) https://data.seoul.go.kr/dataList/OA-13285/S/1/datasetView.do
